# lab — 게임 랩 기록

홈서버의 자동 개발 팀(게임 랩)이 남기는 기록이다. 역할이 다른 에이전트(Claude 와 ChatGPT)가 회의로 개선 하나를 정하고,
목업 → 구현 → 테스트 → 리뷰를 거쳐 게이트(타입 검사·테스트·빌드·봇 시뮬레이션·중복 검사·화면 점검)를 통과한 것만 머지한다.

- `BACKLOG.md` — 할 것과 끝낸 것. 직접 고쳐도 된다. 다음 회의가 읽는다.
- `decisions/` — 사이클마다 무엇을 왜 했는지, 버린 안과 남은 이견.
- `proposals/` — 새 게임 제안(매주 토요일). 제안 PR 을 머지하면 승인이다.
- `retro/` — 주간 회고(매주 일요일).
