## 1. "MSW 콘텐츠 제작 IP 사용 가이드"(terms/1030)와 "넥슨 게임 IP 가이드"(terms/716, /743, /1037)는 무엇을 말하는가? MSW 안에서 쓸 수 있는 넥슨 IP는? 플랫폼 밖 사용은 금지인가?

### Takeaway
MSW IP 가이드는 "가이드에 열거된 게임 IP + 토벤이 직접 제공한 IP"만, **플랫폼 안에서 CGC를 만들고 게시하는 용도로만** 허락하며, 플랫폼 밖에서 넥슨 IP를 쓰는 것은 "엄격히 금지"라고 명시한다(검색 발췌 기준). 넥슨의 일반 게임 IP 가이드는 팬아트·영상 등 2차 창작은 허용하되 **넥슨 IP로 게임을 만들어 배포·서비스하는 것은 원칙적으로 불허**한다.

### Inferences
- MSW에서 메이플스토리 IP를 쓰는 순간 그 월드는 **플랫폼에 묶인다**. 같은 게임을 스팀에 내려면 넥슨 IP(캐릭터·몬스터·맵·BGM·명칭 등)를 전부 걷어내야 한다. MSW 가이드와 일반 게임 IP 가이드 둘 다 같은 방향(플랫폼 밖 게임화 불허)을 가리킨다.
- "2D 횡스크롤 RPG는 원칙적으로 본가와 유사한 것으로 간주"한다는 조항은, 솔로 개발자가 MSW에서 가장 만들기 쉬운 장르(메이플 리소스 기반 횡스크롤 RPG)가 **가장 규제가 강한 장르**라는 뜻이다. 2016년 V 업데이트 이후 IP는 그 장르에서 쓸 수 없다.
- 허용 IP 범위와 기준일은 넥슨/토벤이 일방적으로 바꿀 수 있고 실제로 바꾼 전례(2024-12)가 있다 → 4번 항목 참조.

### Gaps

## 2. 크리에이터가 만든 월드는 누구 것인가(코드·오리지널 아트·게임 디자인)? 같은 게임을 자기 아트로 스팀/모바일에 낼 수 있는가? 넥슨(토벤)은 크리에이터 콘텐츠에 라이선스를 갖는가?

### Takeaway
크리에이터 이용약관(terms/736)은 크리에이터를 CGC의 "크리에이터이자 소유자"로 전제하면서도 **토벤에게 복제·배포·2차적 창작·판매 등 넓은 라이선스를 부여**하게 하고, "CGC 제한적 외부 사용 허락" 조항으로 **플랫폼 밖 사용에 토벤이 별도 조건을 붙일 수 있게** 한다(검색 발췌 기준). 순수 오리지널 자산을 스팀으로 가져가는 것이 금지된다는 문구는 찾지 못했지만, 허용된다는 명시적 문구도 확인하지 못했다.

## 7. 넥슨 Open API 약관: 상업적 이용이 가능한가? 캐릭터·이미지를 새 게임에 쓸 권리를 주는가?

### Takeaway
아니다. Open API 약관은 회사 승낙 없는 **영리 목적 이용을 금지**하고, 이용 승낙이 "등록상표나 저작물에 대한 자유로운 이용권 부여로 해석될 수 없다"고 명시한다(검색 발췌 기준). API는 전적 검색·통계 사이트 같은 데이터 서비스용이지 게임 제작용 IP 라이선스가 아니다.

### Cited Findings
- 영리 이용 금지(발췌): "이용자는 API 서비스를 이용하면서 얻은 일체의 데이터 및 저작물 등을 **회사의 승낙 없이 영리 목적으로 이용**하거나 회사가 허락한 경우 및 그 범위를 초과하여 제3자에게 이용하도록 할 수 없습니다." (검색 요약 기준) — [넥슨 API 이용약관](https://openapi.nexon.com/ko/support/terms/)
- 권리 귀속: API 서비스와 회사가 제작한 프로그램·디자인·상표 등의 지식재산권은 회사에 귀속되고, 결과 데이터의 저작권 등은 회사 또는 제3자에게 있다. **API 이용 승낙이 등록상표나 저작물에 대한 자유로운 이용권 부여로 해석될 수 없다.** (검색 요약 기준) — [넥슨 API 이용약관](https://openapi.nexon.com/ko/support/terms/)
- 결과 데이터 제한: "결과 데이터(넥슨게임의 캐릭터, 서버 정보 등의 메타데이터 및 유저들간의 매치 기록이나 유저들의 게임 진행에 대한 기록 등 넥슨게임 서비스의 컨텐츠 내용에 대한 데이터를 포함)"를 사전 동의 없이 허용 범위를 넘어 복제·저장·가공·배포하거나 제3자에게 재제공하는 행위 금지. (검색 요약 기준) — [넥슨 API 이용약관](https://openapi.nexon.com/ko/support/terms/)
- 출처 표기·브랜드: 결과 데이터 사용 시 "NEXON Open API" 이용 사실을 넥슨이 정한 방식으로 표시해야 하고, 회사 브랜드를 모방·도용하면 안 된다. 위반 시 API 제공 중단 또는 이용계약 해지. (검색 요약 기준) — [넥슨 API 이용약관](https://openapi.nexon.com/ko/support/terms/)
- 게임 IP 가이드와의 관계: "NEXON Open API를 통해 수집한 데이터 및 게임 IP를 사용하는 경우에는 NEXON Open API 서비스 이용 약관이 적용되며", 그 약관에 없는 사항은 게임 IP 사용 가이드가 적용된다. 게임 IP는 세계관·스토리·캐릭터·몬스터·이미지 등 게임을 구성하는 저작물 일체로 정의된다. (검색 요약 기준) — [넥슨 공통 약관 페이지(2024-09-13판)](https://member.nexon.com/policy/policywrapper.aspx?policytype=37&date=20240913)
- 약관은 2023-12 일부 항목이 개정됐다는 공지가 있다. — [서비스 이용약관 일부 항목 변경 안내](https://openapi.nexon.com/ko/support/notice/2449038/)
- 제3자 사례: 메이플스토리 Open API용 오픈소스 라이브러리는 자체 코드에만 MIT 라이선스를 적용하고, 넥슨 API·결과 데이터·게임 이미지·문구·상표에 대한 권리는 부여하지 않으며 MIT의 상업적 사용 허용이 넥슨 데이터의 영리 이용 허용을 뜻하지 않는다고 명시한다. — [GitHub: Kimgooner/maple-kit](https://github.com/Kimgooner/maple-kit)

### Inferences
- Open API로 받아온 캐릭터 이미지·아이템 아이콘·명칭을 **스팀 게임에 넣는 것은 약관상 근거가 없다.** 영리 금지 + "이용권 부여 아님" + 게임 IP 가이드의 "게임 제작·배포 원칙적 불허"가 겹친다.
- 비영리 팬 도구(전적 검색, 계산기)에서 광고를 붙이는 것이 허용되는지는 API 약관 발췌에서 확인되지 않았다. 게임 IP 가이드는 UGC의 광고·후원 수익을 허용하나, 그것이 API 기반 서비스에도 적용되는지는 불명확하다.

### Gaps
- Open API 약관 전문과 최신 개정일, "회사의 승낙"을 받는 절차(상업 제휴 창구)를 확인하지 못했다.
- 광고 수익형 API 활용 사이트에 대한 넥슨의 공식 입장을 확인하지 못했다.

## 종합: 솔로 개발자의 플랫폼 의존 vs 스팀 자가 소유 판단에 쓸 핵심 정리

### Takeaway
MSW는 넥슨 IP와 유저 풀을 빌려 쓰는 대가로 **IP 범위·정책·정산·존속 여부를 넥슨/토벤의 일방적 결정에 맡기는 구조**이고, 메이플스토리 IP를 쓴 결과물은 플랫폼 밖으로 가져갈 수 없다. 스팀으로 가져갈 수 있는 것은 본인이 100% 새로 만든 아트·기획·(새로 작성한) 코드뿐이다.

- 플랫폼 밖 넥슨 IP 사용은 "엄격히 금지". — [MSW IP 사용 가이드](https://m.nexon.com/terms/1030)

### Inferences
- **할 수 있는 것**: MSW 안에서 허용 범위의 메이플스토리·바람의나라 등 IP로 월드를 만들고 유료 상품을 팔아 수익을 얻는 것. 원작과 다른 장르는 IP 시점 제한이 완화된다(넥슨 해명 기준). 본인 오리지널 자산을 섞어 쓰는 것.
